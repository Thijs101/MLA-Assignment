# Claude assignment - MLA Fashion-MNIST project

The three files ready to submit on Canvas:

- `report.pdf` - final report.
- `technology_statement.pdf` - technology statement.
- `code.zip` - the code, zipped (this is a copy of `code/`; keep the two in sync if you edit one).

Everything else is source/working material, not a submission file:

- `code/` - the Part 1 analysis code, unzipped. See `code/README.md` for how to run it.
- `latex/` - the LaTeX source. `report.tex` and `technology_statement.tex` reference
  images inside `latex/figures/`, so to edit in Overleaf, create a new project and
  upload the whole `latex/` folder (or zip it and use "Upload Project") so the
  `figures/` subfolder comes along with it.
- `results/metrics.json` - the raw numbers the report quotes.
