# Claude assignment - MLA Fashion-MNIST project

The three files to submit on Canvas:

- `report.pdf` - final report (main text exactly 3 pages; figures and tables in the appendix).
- `technology_statement.pdf` - technology statement (sign before submitting).
- `code.zip` - the code, zipped (a copy of `code/`).

Working material:

- `overleaf_project.zip` - upload to Overleaf via New Project > Upload Project
  (`report.tex`, `technology_statement.tex` and the figures the report uses).
- `code/` - the code, unzipped. See `code/README.md` for how to run it.
- `latex/` - the same LaTeX source. Images in `latex/figures/` that are not used by
  `report.tex` are from earlier versions and can be deleted.
- `results/` - the raw numbers the report quotes.
